Each river/year has a candidate pool of up to 15 randomly-selected fish, of which 10 need imaging (the rest are kept in reserve for poor scale quality). Required = that target, capped by however many candidates exist. Imaged = candidates with a scale image on file (Bilde_skjell) counted toward the target. Excess = already-imaged candidates beyond the target — extra coverage that isn't needed to hit 100% but exists anyway. Many images predate this project (imaging under NASCO project 132668 begins October 2026); this view tracks total coverage, not only new NASCO imaging. Data refreshes daily from the project's source spreadsheet.
